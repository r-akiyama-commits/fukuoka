地図をタップして位置を指定

背景の地図画像はこのプレビュー枠では読み込めません。かわりに主要駅・目盛り・距離スケールで位置関係を出しています。ダウンロードしてSafariなどで開くと通常の地図が表示されます。

リンクは座標を含む形式（アドレスバーのURL）なら読み取れます。maps.app.goo.gl の短縮リンクは座標が入っていないので、地図タップで指定してください。位置は後から設定してもかまいません。

  1. console.firebase.google.com でプロジェクトを作る
  2. 左メニューの Realtime Database → データベースを作成 → ロケーションは asia-southeast1 → 「テストモードで開始」
  3. 表示された https://... のURLを上に貼る
  4. Rules タブを開き、read と write を true にして公開（テストモードは30日で切れます）
  5. スマホでも同じURLと合言葉を入れる
　
Dayの数字を押すと日程を入れ替えられます。「−」は未定。右端の▲▼で同じDay内の順番を変えられます。
店名の横のジャンルタグを押すと、そのジャンルを書き換えられます。入力欄には候補が出ますが、ない言葉を打てばそのまま増えます。
車の所要時間はオンラインなら実際の道路を通るルートで計算します。渋滞・信号・駐車の時間は入っていないので、市街地は1.3倍くらいで見ておくと安全です。オフラインのときは距離からの概算に切り替わります。
時刻は目安です。営業時間・定休日は行く前に「マップで開く」で確認してください。
